# Design context

- **Audience**: one person (the owner) checking a dashboard of their own Amazon wishlists, a few times a week, usually on desktop, sometimes phone.
- **Use cases**: glance at list health, scan a long item table for what's on sale, set a target price, pause a list, trigger a check.
- **Tone**: cool and crisp. Slate and off-white surfaces, one strong blue for actions and links, teal for "on sale / good", amber for stale, red for broken. Feels like a small finance app: dense, calm, legible. No decoration for its own sake.
- **Constraints**: one static HTML file, no build step, no framework, system font stack, light and dark via `prefers-color-scheme`, WCAG AA contrast, keyboard-usable.
- **Brand colors**: none inherited. Palette is defined in `public/index.html` `:root` and is the source of truth.
